## HUD typefaces

The ArrayList HUD ships eight typefaces, each in a Medium and a SemiBold
weight. The first four are taken from the Clawd project:

- **Inter** by Rasmus Andersson - SIL Open Font License 1.1
  (https://github.com/rsms/inter/blob/master/LICENSE.txt)
- **Poppins** by Indian Type Foundry, Jonny Pinhorn - SIL Open Font License 1.1
  (https://github.com/itfoundry/Poppins/blob/master/OFL.txt)
- **Roboto** by Christian Robertson (Google) - Apache License 2.0
  (https://github.com/googlefonts/roboto/blob/main/LICENSE)
- **JetBrains Mono** by JetBrains - SIL Open Font License 1.1
  (https://github.com/JetBrains/JetBrainsMono/blob/master/OFL.txt)

The remaining four:

- **Rajdhani** by Indian Type Foundry - SIL Open Font License 1.1
  (https://fonts.google.com/specimen/Rajdhani/license)
- **Ubuntu** by Dalton Maag - Ubuntu Font Licence 1.0
  (https://ubuntu.com/legal/font-licence)
- **Play** by Jonas Hecksher - SIL Open Font License 1.1
  (https://fonts.google.com/specimen/Play/license)
- **Raleway** by Matt McInerney, Pablo Impallari, Rodrigo Fuenzalida -
  SIL Open Font License 1.1
  (https://fonts.google.com/specimen/Raleway/license)
